# Gestion de Pacientes
Utilizada por el personal de recepción, que podrá acceder rápidamente a cada una de estas opciones y consultar la información del paciente
1. Permite consultar un turno, ingresando el DNI del paciente para verificar la fecha,
horario y estudio correspondiente.
2. Permite sacar un turno, seleccionando el estudio y uno de los horarios disponibles
para el paciente.
3. Permite consultar y registrar el retiro de un resultado, verificando previamente si
el estudio ya se encuentra disponible.
